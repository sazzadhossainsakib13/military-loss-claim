# ⚖️ Military Hearing Loss Claim Landing Page

A responsive legal service lead-generation landing page designed for military claim consultations and case reviews.

---

## Overview

This repository contains a legal consultation landing page built to inform military service members about hearing loss claims and capture case review inquiries. It features structured information sections, eligibility criteria checklists, and responsive form components.

---

## Features

- **Lead Generation Intake Form**: Interactive consultation request form with input fields for personal contact details and claim history.
- **Sticky Navigation CTA**: Persistent top banner guiding users toward the evaluation form.
- **Structured Legal Disclaimers**: Informational breakdowns explaining claim eligibility criteria and settlement timelines.
- **Responsive Layout**: Multi-column grid optimized across desktop and mobile screen sizes using Bootstrap 4.

---

## Tech Stack

- **Markup & Layout**: HTML5, CSS3
- **CSS Framework**: Bootstrap 4.5
- **Icons**: Font Awesome 4.7
